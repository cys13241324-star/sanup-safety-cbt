# 독끝 조판 파이프라인

산업안전기사 기출 원고를 『2027 전기기능사 필기』 2권 Part C 의 조판 규격으로
자동 조판하는 도구 모음. HWPX(한글 문서의 XML 포맷)를 직접 생성한다.

**이 폴더에는 스크립트만 있다.** 템플릿 조각·원고·산출물은 상업 출판물의 자산이라
저장소에 넣지 않았다. 아래 환경변수로 각자 위치를 가리켜 쓴다.

```
DOKKEUT_TPL      템플릿 HWPX (전기기능사 Part C)
DOKKEUT_LAYOUT   약물 EMF·박스 타일이 든 레이아웃 폴더
DOKKEUT_FIG      문항 그림 폴더
```

## 어떻게 도는가

원고(JSON) → `build.py` → HWPX → 한글로 열어 PDF → 측정 → 되먹임 → 다시 빌드.

템플릿의 `header.xml`·`BinData`·`borderFill` 을 통째로 재사용하고
`Contents/section0.xml` 만 새로 만든다. 스타일이 이름으로 정의돼 있어 그대로 승계된다
(문제-번호 · 문제 · 문항 · 해설-내용 · 해설-오답분석 · 학습포인트-제목/내용 · 관련이론 …).

```
build.py       조판 본체. 문항 JSON 을 읽어 HWPX 를 만든다
colfit.py      단별 하단 여백 측정 → gaps.json (문항 사이 간격 단계)
colloop.ps1    build → 한글 PDF → colfit 을 반복해 하단을 맞춘다
orphan.py      마지막 줄이 한두 글자인 문단을 찾아 자간·장평을 조인다
loop.ps1       orphan 되먹임 루프
qa_content.py  원고 결손 점검 (발문이 가리키는 그림·표·보기가 실제로 없는 문항)
extract.py     템플릿에서 문항 블록 XML 조각을 뜯어낸다
extract2.py    조각 선별 + 텍스트 노드 지도
fontscan.py    설치된 폰트의 실제 패밀리 이름을 읽어 문서 요구와 대조
com_typeset.py 한글 COM 으로 직접 찍는 조판기 (녹화용, 참고 구현)
record_*.py    조판 과정 화면 녹화
```

## 조판 규칙

- **판형** 198×267mm(재단 188×257) · 2단 · 단폭 66.5mm · 사이 10mm
- **덩어리** ① 문제번호+발문+보기 ② 해설 약물+본문 ③ 오답분석 약물+3항목
  ④ 학습 Point 박스+관련이론 바 — 중간에 끊기지 않고, 안 들어가면 통째로 다음 단으로
- **단 최상단** 덩어리 첫 문단의 위 여백을 0으로 두고 그만큼을 앞 문단의 아래 여백으로
  옮긴다. 그래야 단이 바뀔 때 여백이 잘려 최상단에 붙는다
- **하단 맞추기** 단에 남는 공간을 그 단 안의 문항 사이 간격으로 흩는다
- **표** 셀 가운데정렬 · 열 폭은 내용 길이로 잡되 짧은 항목명이 줄바꿈되지 않도록 우선 확보
  · 두 줄이 되면 첫 줄이 조금 더 길게 균형
- **표기** 강조·수식·단위 뒤 조사는 붙이고(`220[V]를`), 이상·이하·초과는 띄운다(`50[kV] 이하`)

## HWPX 생성 함정

한글은 잘못된 입력에 오류를 내지 않고 조용히 무시하거나 파일을 안 연다. 겪은 것들:

1. **id 는 배열 인덱스다.** `charPr`/`paraPr`/`style` 의 `id` 는 이름표가 아니라 순번이라
   임의 번호(900 등)를 쓰면 무시된다. 마지막 id 다음 번호로 연속 배정하고 `itemCnt` 도 올린다.
   **문서에 나오는 순서도 id 순이어야 한다** — 사본을 두 덩어리로 나눠 붙이면 참조가 통째로 밀린다.
2. **정렬은 스타일이 이긴다.** `paraPrIDRef` 만 바꿔서는 안 먹는다. 스타일 사본을 만들어야 한다.
3. `<hp:secPr>` 는 `<hp:run>` 의 직계 자식. `<hp:ctrl>` 로 감싸면 한글이 죽는다.
4. **섹션을 지우면 고칠 곳이 넷** — `content.hpf`(item+itemref) · `container.rdf` ·
   `header.xml` 의 `secCnt` · `settings.xml` 의 `CaretPosition listIDRef`.
5. **`linesegarray` 를 직접 넣지 말 것.** 고정값을 넣으면 여러 줄 문단의 글자가 겹쳐 찍힌다.
   비워 두면 한글이 열면서 다시 계산한다.
6. `<hp:t>` 는 혼합 콘텐츠다. 보기는 `①<hp:tab/>보기텍스트` 이고 텍스트는 tab 의 tail 에 있다.
   **단일 run 이어야** 탭이 내어쓰기 위치에 붙는다.
7. **수식이 든 문단은 왼쪽정렬로.** 수식 개체는 줄바꿈이 안 돼, 양쪽정렬이면 남은 낱말이
   단 오른쪽 끝까지 밀린다(실측 109pt).
8. 짝수 쪽은 제본 여백이 뒤집혀 단이 14pt 왼쪽에 있다. 측정 도구가 이걸 놓치면
   짝수 쪽 문항을 통째로 못 본다.
9. 템플릿의 EMF 는 외부 링크(`isEmbeded="0"`)라 경로가 없으면 조용히 안 그려진다.
   본문과 테두리채우기가 참조하는 이미지를 모아 임베드 여부를 검사할 것.
